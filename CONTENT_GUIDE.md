# Content Guide

This portfolio is managed from `src/content/site.js`.

- Edit `person` for name, role, email, resume, portrait, and social links.
- Edit `projects` for portfolio cards.
- Edit `thoughts` for manual blog/post entries.
- Edit `lens` for photography sets. For Google Photos, create a public album share link and paste it into `href`.
- Put local images in `public/assets/img/... ` and reference them with paths like `/assets/img/example.jpg`.

After edits, run:

```sh
npm run build
```
